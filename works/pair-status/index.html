紹介サイトとデモを見る（新しいタブ）

正式サービスではなく、個人開発のPortfolio Editionです。
公開デモは実認証・DBから分離し、合成データのみで動作します。

伝える負担を、
小さくしたかった。

日々の気持ちは、いつも上手に言葉にできるとは限りません。表情を選ぶ小さな操作が、相手に伝えるきっかけになればと考えて制作しました。

表情・メモ・写真の共有と、カレンダーからの振り返りを実装しています。ホームでは自分と相手を色で区別し、感情名を並べずに表情を中心に見せる構成にしました。読み上げ用の情報は残しています。

見せ方と、
データの境界を考える。

更新されても、誰の情報かを見失わない。

本人と相手の投稿を区別し、未投稿・前日の投稿・通信失敗を分けて扱うことを重視しました。取得に失敗して保持した情報を、最新の取得成功と同じ状態にしないようにしています。

毎日の操作を、スマートフォンで整える。

大きな表情と共有ボタンを両立するために、余白・プロフィール・状態表示の重複を見直しました。文字拡大や更新中も含めて、画面の一場面だけで判断しないようにしました。

登録しなくても、作品に触れられる。

公開版ではデータと通信の入口を分離し、実サービスに接続せず投稿や振り返りを操作できるようにしました。公開デモの検証と、実認証・実端末での検証は区別して記録しています。

構成と、学び。

React / JavaScript / CSS · Java / Spring Boot · PostgreSQL / Supabase

状態が更新される画面では、正常時の表示を整えるだけでは不十分でした。誰の情報か、いつの情報か、取得が成功したかを、画面の表現と一緒に考えることの大切さを学びました。

今後は第三者の操作レビューや実iPhoneでの確認を通して、伝わりやすさと操作性をさらに確かめたいと考えています。
