HABIT ROOM

「続けられる」を、つくる。
初心者の一歩を支える、店舗サイト。

制作サイトを見る（新しいタブ）

店舗・スタッフ・価格・サービスは、架空の制作サンプルです。
実店舗や実予約ではありません。

初心者の不安を、
情報の順序でほどく。

ジムに興味があっても、体力や料金、続けられるかが気になる。その不安を、具体的な情報で減らせるサイトを目指しました。

プログラム、税込料金、スタジオ紹介、FAQ、体験予約デモをつなぎ、判断に必要な情報へ進めるようにしています。50分のプログラム、月2回からのプランといった設定を短く示し、写真と文字の優先順位を整えました。

雰囲気と実用性を、
両立させる。

写真を生かし、情報は埋もれさせない。

黒・アイボリー・ライムを使い、強い文字組みと余白でリズムをつくりました。装飾を増やすより、見出しと料金・体験予約への導線を明確にしています。写真はイメージ素材として扱い、実在スタッフや顧客の写真とは紹介していません。

予約の流れを、安全なデモに。

入力・バリデーション・確認・修正・終了まで、ブラウザ内で体験できます。サーバーへの送信や実際の予約成立、完了メールの送付は行いません。

公開と、更新しやすさを考える。

Astroの静的ビルドを使い、共通のナビゲーションとCTAを整理しました。公開先のパスやメタデータを設定で扱い、ルートとサブディレクトリの配信を検証しています。

MOBILE FIRST

小さな画面でも、
選べる・分かる。

320pxからの画面幅、文字200%、キーボード操作を確認。Chromium・Firefox・WebKitで、表示と予約デモを検証しました。

ブラウザの自動検証は、実iPhoneや支援技術での操作確認とは分けています。

構成と、学び。

Astro / TypeScript / CSS · Playwright / Lighthouse

店舗サイトでは、魅力を伝える写真と、判断するための具体的な情報の両方が必要だと感じました。静的サイトでも、フォームの状態や公開先の違いまで考えることで、制作の品質を積み上げられました。

公開後も表示とリンクを確認し、実端末での操作確認を重ねていきます。
