WEBSITE / FICTIONAL BRAND

LUMÉ

髪に、余白を。
自然光が入る小さなヘアサロンのWebサイト。

自主制作の架空店舗サイトです。掲載内容は制作サンプルで、実店舗への案内や予約受付はありません。

制作サイトを見る（新しいタブ）

店舗の空気と、
来店前に知りたいこと。

美容室を探している人が、まず店の雰囲気を感じ、次に施術と料金を確認できるサイトを目指しました。内装写真と余白で静かな印象をつくり、必要な情報を1ページで順に読めるようにしました。

メニューには税込価格と所要時間を添え、金額の末尾を揃えました。スタッフ写真は紹介文を補う大きさに抑え、ご来店の流れから架空の地図へ移動できるようにしました。

小さな画面でも、
迷わず読めるように。

390・768・1440pxで画面を確認。Chromiumで画像の読み込み、横スクロール、ページ内リンクとキーボード操作を検証し、画面修正の前後もスクリーンショットで比較しました。

使用技術

HTML / CSS / WebP · Playwright / Chromium

内装と人物のイメージはこの作品用に生成し、地図はHTML・CSSで作図しました。外部フォントや地図API、予約フォームを使わない静的な構成です。
